# **06\. Το Τεστ Συναίνεσης (3-Second Rule): Θέλει όντως ο σκύλος σας να τον χαϊδεύετε αυτή τη στιγμή;**

**Κατηγορία:** 12 - Πώς Εκφράζονται τα Σκυλιά (Γλώσσα Σώματος & Σήματα Ηρεμίας)  
**Προτεινόμενο URL:** /blog/test-synainesis-sta-xadia-skylou  
**Χρόνος ανάγνωσης:** 2 λεπτά

**Με μια ματιά (TL;DR)**

> * Μια μικρή παύση μας βοηθά να παρατηρήσουμε αν επιθυμεί συνέχεια.
> * Τα «τρία δευτερόλεπτα» είναι υπενθύμιση, όχι επιστημονικό τεστ ασφάλειας.
> * Η απουσία αντίστασης δεν ισοδυναμεί με επιθυμία για επαφή.

## **Ρωτάμε μέσα από τη συμπεριφορά μας**

Η συναίνεση εδώ περιγράφει την πρακτική να δίνουμε επιλογή, όχι ανθρώπινη νομική έννοια. Ένας σκύλος μπορεί να απολαμβάνει χάδια κάποιες στιγμές και άλλες να χρειάζεται ησυχία.

Η προσέγγιση για μύρισμα δεν είναι απαραίτητα πρόσκληση να τον αγκαλιάσουμε. Μπορεί να θέλει μόνο πληροφορίες ή να περιμένει φαγητό.

## **Μια απλή διαδικασία**

1. **Περιμένετε εθελοντική προσέγγιση:** Μην τον φωνάζετε κοντά μόνο για να τον κρατήσετε.
2. **Αγγίξτε ήπια και σύντομα:** Σε γνώριμο σκύλο, ξεκινήστε από σημείο που προτιμά, συχνά πλάγια στον ώμο ή στο στήθος.
3. **Αποσύρετε τα χέρια:** Μετά από λίγα δευτερόλεπτα, κάντε παύση χωρίς να τον κοιτάζετε επίμονα.
4. **Παρατηρήστε την απάντηση:** Αν πλησιάζει ξανά χαλαρά, μπορείτε να συνεχίσετε. Αν φεύγει, στρέφει το κεφάλι ή παγώνει, σταματήστε.

## **Όρια της διαδικασίας**

Δεν εφαρμόζουμε το «τεστ» ως τρόπο προσέγγισης σκύλου με ιστορικό δαγκώματος. Δεν ενοχλούμε ύπνο, φαγητό ή ανάπαυση για να ελέγξουμε αν θέλει χάδια.

Παιδιά χρειάζονται ενήλικη καθοδήγηση και ασφαλή χωρισμό όταν δεν υπάρχει επίβλεψη. Αν εμφανιστεί ξαφνική ευαισθησία σε γνώριμο άγγιγμα, εξετάστε πόνο με κτηνίατρο. Ο σεβασμός στην απομάκρυνση είναι ουσιαστικότερος από την ακριβή μέτρηση δευτερολέπτων.

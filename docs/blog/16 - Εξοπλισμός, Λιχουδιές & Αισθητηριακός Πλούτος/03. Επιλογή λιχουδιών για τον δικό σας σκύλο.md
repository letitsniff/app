# **03\. Η ιεραρχία των λιχουδιών: Πώς βρίσκουμε τι αξίζει για τον δικό μας σκύλο**

**Κατηγορία:** 16 - Εξοπλισμός, Λιχουδιές & Αισθητηριακός Πλούτος  
**Προτεινόμενο URL:** /blog/ierarxia-lixoudion-ekpaidefsi-skylou  
**Χρόνος ανάγνωσης:** 2 λεπτά

**Με μια ματιά (TL;DR)**

> * Η αξία της ανταμοιβής καθορίζεται από τον σκύλο και τη στιγμή.
> * Μικρές, κατάλληλες μπουκιές διευκολύνουν τον χρονισμό.
> * Πιο νόστιμο φαγητό δεν αντισταθμίζει πάντα ένα υπερβολικά δύσκολο περιβάλλον.

## **Δεν υπάρχει κοινή κατάταξη για όλους**

Τυρί, κοτόπουλο ή ξηρά τροφή δεν έχουν ίδια αξία για κάθε σκύλο. Προτιμήσεις, κορεσμός και υγεία αλλάζουν τις επιλογές. Μερικές φορές η καλύτερη ανταμοιβή είναι να μυρίσει ή να απομακρυνθεί από κάτι δύσκολο.

Η άρνηση τροφής δεν αποδεικνύει πάντα φόβο, αλλά είναι λόγος να επανεξετάσουμε την άσκηση. Δεν πιέζουμε και δεν αφήνουμε νηστικό τον σκύλο για να συνεργαστεί.

## **Οργανώστε τις ανταμοιβές**

1. **Δοκιμάστε σε ήρεμο χώρο:** Μικρές ποσότητες κατάλληλων τροφών που επιτρέπονται στη διατροφή του.
2. **Κόψτε μικρές μπουκιές:** Να καταπίνονται εύκολα χωρίς να διακόπτουν συνεχώς τη ροή της άσκησης.
3. **Κρατήστε σωστά τα ευπαθή τρόφιμα:** Μικρές ποσότητες, κατάλληλη ψύξη και καθαρό τσαντάκι. Όχι πολλές ώρες στη ζέστη.
4. **Υπολογίστε τη συνολική διατροφή:** Οι λιχουδιές δεν πρέπει να εκτοπίζουν την πλήρη τροφή. Για αλλεργίες ή ειδική δίαιτα ρωτήστε κτηνίατρο.

## **Όρια ασφάλειας**

Αποφύγετε ξυλιτόλη, σοκολάτα, σταφύλια, σταφίδες και ακατάλληλα καρυκευμένα τρόφιμα. Το τυρί δεν είναι αναγκαίο και μπορεί να μην ταιριάζει σε σκύλο με πεπτική ευαισθησία.

Αν δεν ανταποκρίνεται ούτε σε αγαπημένη ανταμοιβή, αυξήστε απόσταση ή σταματήστε. Η σωστή δυσκολία είναι σημαντικότερη από μια διαρκή αναζήτηση «ισχυρότερης» λιχουδιάς.

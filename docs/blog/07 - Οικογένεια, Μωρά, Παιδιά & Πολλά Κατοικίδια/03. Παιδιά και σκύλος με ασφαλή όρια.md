# **03\. Παιδιά και Σκύλος: Οι 5 χρυσοί κανόνες ασφαλείας που πρέπει να ξέρει κάθε γονιός**

**Κατηγορία:** 07 - Οικογένεια, Μωρά, Παιδιά & Πολλά Κατοικίδια  
**Προτεινόμενο URL:** /blog/paidia-kai-skylos-kanones-asfaleias  
**Χρόνος ανάγνωσης:** 2 λεπτά

**Με μια ματιά (TL;DR)**

> * Η ευθύνη ασφάλειας ανήκει στον ενήλικα, όχι στο παιδί ή στον σκύλο.
> * Η επίβλεψη πρέπει να είναι ενεργή.
> * Όταν η προσοχή αποσπάται, χρησιμοποιούμε ασφαλή χωρισμό.

## **Η εξοικείωση δεν καταργεί τον κίνδυνο**

Ένας σκύλος που ζει χρόνια με την οικογένεια μπορεί να πονέσει, να τρομάξει ή να δυσκολευτεί όταν τον αγκαλιάζουν. Δεν περιμένουμε να γρυλίσει για να παρέμβουμε, ούτε θεωρούμε ότι ένα μικρό παιδί μπορεί να διαβάσει σωστά όλα τα σήματα.

Οι κανόνες πρέπει να εφαρμόζονται από όλους, ακόμη και όταν η αλληλεπίδραση φαίνεται χαριτωμένη.

## **Πέντε κανόνες για το σπίτι**

1. **Ύπνος και φαγητό χωρίς ενόχληση:** Κρεβάτι, μπολ και μασήματα βρίσκονται σε χώρο που δεν πλησιάζουν τα παιδιά.
2. **Όχι αγκαλιές και πρόσωπο στη μουσούδα:** Δεν τραβάμε αυτιά, ουρά ή τρίχωμα και δεν καβαλάμε τον σκύλο.
3. **Ο σκύλος μπορεί να φύγει:** Δεν τον στριμώχνουμε σε γωνία και δεν τον ακολουθούμε όταν απομακρύνεται.
4. **Ήρεμη συμμετοχή με ενήλικα:** Το παιδί μπορεί, όταν είναι κατάλληλο για την ηλικία του, να βοηθά σε απλές δραστηριότητες από ασφαλή απόσταση.
5. **Χωρισμός όταν δεν επιβλέπουμε:** Τηλέφωνο, μαγείρεμα και ύπνος δεν συνδυάζονται με ενεργή επίβλεψη επαφής.

## **Τι κάνουμε όταν κάτι αλλάζει**

Αν ο σκύλος παγώσει, αποστρέψει το κεφάλι, προσπαθήσει να φύγει ή γρυλίσει, ο ενήλικας διακόπτει ήρεμα και απομακρύνει το παιδί. Δεν ζητάμε να τον χαϊδέψει για «συγγνώμη».

Σε νέο φόβο, πόνο ή επιθετική συμπεριφορά ζητήστε κτηνιατρική και συμπεριφορική αξιολόγηση. Αν υπάρξει δάγκωμα, ασφαλίστε πρώτα τον χωρισμό και αναζητήστε ιατρική φροντίδα.
